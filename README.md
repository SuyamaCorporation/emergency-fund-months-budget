# Emergency Fund Months of Expenses Budget Planner
Plan and track your emergency fund by itemizing expenses and visualizing progress toward 3, 6, or 12 months of coverage.
## Features
- Itemize monthly expenses (rent, food, utilities, etc.) with add/remove rows
- Input current savings and monthly savings contribution
- 3 / 6 / 12 month target selector
- Animated progress bar showing current vs. target
- If short: displays shortfall amount, months to reach goal, and projected target date
## Tech
Static SPA · Tailwind CDN · localStorage
